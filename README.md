# climate-newsletter-skill

KIST 청정대기센터의 주간 **'청정대기 이슈동향'** 뉴스레터 작성을 자동화하는 Claude 스킬입니다.
기후변화·대기환경 관련 국내외 정책 기사와 최신 학술 논문을 수집·검증·요약하여, 기존 발간 양식과 동일한 HTML/DOCX 뉴스레터를 생성합니다.

## 주요 기능

- **소스 자동 수집**: 정책브리핑, WMO, IEA, Nature 계열 저널 등 검증된 매체·저널 목록을 기준으로 지난 1주일간의 국내외 정책 및 최신 연구 후보를 섹션별 5~6건씩 탐색
- **4대 필수 검증 내장**: 발행일(7일 이내), 섹션 분류 적합성, 주제 관련성, 논문 서지정보(Crossref)를 후보 제시 전에 자동 재확인하여 할루시네이션과 오류를 차단
- **사용자 선정 → 요약 → 산출물 생성**: 후보 목록에서 사용자가 항목을 선택하면 스타일 가이드(격식체, 섹션별 분량 기준: 기사 500~700자 / 논문 600~800자)에 따라 요약을 작성하고, 이메일 발송용 HTML과 검수용 DOCX를 동시 생성

## 뉴스레터 구성

| 섹션 | 최소 건수 | 요약 분량 |
|------|----------|----------|
| 국내 정책·연구 | 2건 | 500~700자 |
| 해외 정책·연구 | 2건 | 500~700자 |
| 최신 연구 동향 (논문) | 2건 | 600~800자 |

## 저장소 구조

```
climate-newsletter-skill/
├── SKILL.md                        # 메인 워크플로우 (Step 1~6)
├── references/
│   ├── style-guide.md              # 요약 작성 스타일 상세 지침
│   ├── sources.md                  # 매체/저널 목록, 전문지 티어, 차단 도메인 목록
│   └── archive.md                  # 최근 발간 호 수록 항목 기록 (중복 방지용)
├── scripts/
│   ├── generate_newsletter.py      # HTML + DOCX 생성 스크립트
│   └── verify_doi.py               # Crossref 기반 논문 서지정보 검증 스크립트
└── assets/
    └── template_raw.html           # 원본 HTML 템플릿
```

## 사용 방법

1. Claude(claude.ai)에 이 스킬을 설치합니다.
2. 다음과 같이 요청하면 스킬이 자동으로 작동합니다.
   - `"이번 주 뉴스레터 만들어줘"` — 웹 검색 기반 자동 수집
   - URL 목록 제공 — 제공된 기사/논문을 우선 반영하고 부족한 섹션만 자동 탐색
   - `"3월 셋째주 뉴스레터"` — 특정 기간 지정
3. 제시된 후보 목록에서 수록할 항목을 선택하면 요약 작성 후 HTML/DOCX 파일이 생성됩니다.
4. 발간 후 Claude가 생성해주는 아카이브 기록 라인을 `references/archive.md`에 붙여넣습니다 (다음 호 중복 방지).

## 업데이트 내역

### v1.1 (2026.06)

운영 과정에서 발견된 문제를 보완한 고도화 업데이트입니다.

**1. 차단 도메인 대응 프로토콜 명문화**
- 정책브리핑(korea.kr), 연합뉴스(yna.co.kr) 등 원문 접근이 차단되는 도메인에 대해 우회 경로를 순차 시도: ① 네이버 뉴스 미러 → ② 부처 원본 보도자료 → ③ RSS
- 모든 우회 실패 시 해당 항목에 `⚠️ 원문 미확인` 표시 후 작성자에게 본문 제공을 요청하는 절차를 규칙화. 검색 스니펫만으로 요약을 작성하는 것을 금지하여 할루시네이션 위험을 구조적으로 차단

**2. 소스 확장 — '전문지' 티어 신설** (`references/sources.md`)
- 헬로디디(출연연·대덕특구 연구성과), 지디넷코리아(기후×기술 교차 이슈), 전자신문(에너지·산업기술)을 적용 조건과 함께 추가하여 전문 영역 커버리지 확대

**3. 이전 호 중복 방지 구조화** (`references/archive.md`)
- 최근 4주간 수록 항목을 누적 기록하고, 소스 수집 단계에서 이를 참조해 중복 후보를 자동 제외
- 매호 발간 후 기록 라인을 한 번 붙여넣는 가벼운 방식으로 운영 부담 최소화

**4. 논문 서지정보 자동 검증** (`scripts/verify_doi.py`)
- Crossref API 연동으로 DOI 기준 제목·저자·게재일·저널명을 자동 확인
- 실행 환경의 네트워크 제약에 대비한 3단계 폴백 설계: 스크립트 → Crossref web_fetch → 논문 원문 페이지 직접 대조

### v1.0

- 최초 공개: 소스 수집 → 3대 검증 → 사용자 선정 → 요약 → HTML/DOCX 생성 워크플로우

## 운영 시 유의사항

- 스킬 폴더는 Claude 실행 환경에서 읽기 전용이므로, `archive.md` 갱신과 차단 도메인 목록 추가는 이 저장소에서 직접 수정 후 스킬을 재설치해야 반영됩니다.
- 새로 fetch 차단이 확인된 도메인은 `references/sources.md`의 차단 도메인 표에 추가해 주세요.
- 뉴스레터 템플릿(양식) 변경 시 `assets/template_raw.html`과 `scripts/generate_newsletter.py`를 함께 수정해야 합니다.
