# 청정대기 이슈동향 뉴스레터 요약 작성 스타일 가이드

이 가이드는 기존 발간 뉴스레터 분석 및 사용자 피드백을 반영한 구체적 서술 지침이다.

---

## 공통 원칙

### 어체 및 종결어미
- **격식체(합쇼체)** 사용: "~하였다", "~밝혔다", "~것으로 나타났다", "~전망이다", "~예정이다"
- 절대로 사용하지 않는 어체: 해요체("~해요", "~있어요"), 반말("~했다"는 OK, "~했음"은 NG)
- 종결어미 패턴 예시:
  - 사실 전달: "~것으로 나타났다", "~것으로 확인되었다", "~것으로 분석됐다"
  - 기관 발표: "~라고 밝혔다", "~라고 발표하였다", "~라고 강조했다"
  - 전망/예측: "~것으로 전망이다", "~것으로 예측됐다", "~것으로 기대된다"
  - 계획: "~할 예정이다", "~할 계획이다", "~을 추진한다"

### 기사 제목
- **반드시 원문 기사의 제목을 그대로** 사용한다
- 절대로 제목을 임의로 생성하거나, 요약하거나, 변형하지 않는다
- 원문 기사 페이지에서 정확한 제목을 확인하고 그대로 복사한다

### 출처 매체명
- 실제 기사가 게재된 매체의 정확한 이름을 기재한다
- 기사를 직접 확인하지 않은 매체를 출처로 적지 않는다
- 같은 내용이 여러 매체에 보도된 경우, 실제로 링크를 제공하는 기사의 매체명을 기재

### 숫자·데이터 활용
- 구체적 수치를 적극 포함: 예산 금액, 퍼센트, 농도값, 온도, 면적 등
- 단위는 원문 그대로 유지: ㎍/㎥, ppm, ℃, Gt, ZJ 등
- 수치는 아라비아 숫자로 표기: "약 70명", "1억 320만 달러", "166억 톤"
- 연도·날짜 표기: "2024년 12월", "지난 30일", "12월 11일부터"

### 전문용어 처리
- 영문 약어 첫 등장 시 풀네임(약어) 병기: "세계기상기구(WMO)", "국립환경과학원"
- 이후 약어만 사용 가능
- 학술 전문용어는 영문 병기: "압력 능선(pressure ridges)", "새로운 입자 형성(NPF)"
- 주석이 필요한 경우 본문의 해당 용어 뒤에 `*`(또는 `¹`, `²`)를 붙이고, 설명은 JSON `footnotes` 필드에 넣는다. 스크립트가 출처 아래에 회색 12px 각주 블록으로 출력한다
- 각주 대상: 본문에서 풀어 쓰면 흐름이 끊기는 용어·제도명·수치 기준(예: 배출권 유상할당률, 복사강제력, PM2.5 환경기준). 항목당 1~3개 이내, 각 1문장

### 인용 및 마무리
- 마지막 1~2문장은 **전문가/관계자의 발언 인용** 또는 **시사점/의의 제시**로 마무리
- 인용 형식: 연구진은 "인용문"이라며, "후속 인용문"이라고 강조했다.
- 또는: 본 연구는 ~에 기여한다 / ~을 시사한다 / ~한 데 큰 의의가 있다

## 섹션별 서술 패턴

### 1. 국내 정책·연구 (500~700자)

#### 소스 원칙
- **대한민국 정책브리핑(korea.kr)을 최우선** 소스로 활용
- 언론사 기사는 **주요 대형 언론사만** 선정 (연합뉴스, 동아사이언스, 조선비즈, 뉴시스, 한겨레, 경향신문, 중앙일보 등)
- 소규모·지역 언론사(경인방송, 지역MBC, 소규모 인터넷언론 등)는 **사용하지 않는다**
- 같은 기사가 여러 매체에 나왔다면 대형 언론사 버전을 선택

#### 구조 패턴
```
[주체 기관]은(는) [행위/발표 내용]을(를) [시점]에 [행위동사].
→ 배경 및 맥락 설명 (1~2문장)
→ 주요 내용 상세 (2~4문장, 수치/데이터 포함)
→ 관계자 발언 인용 또는 의의/향후 계획 (1~2문장)
```

#### 실제 패턴 예시
- **첫 문장**: 기관 주어로 시작
  - "기후에너지환경부는 ~을 확대한다고 밝혔다."
  - "과학기술정보통신부는 ~에 총 862억 원을 투자한다고 밝혔다."
  - "국립환경과학원은 ~을 실시간으로 제공한다."
- **중간부**: 정책의 구체적 내용, 수치, 기대 효과
- **마지막**: "~장은 '...'이라고 밝혔다" 또는 "~을 추진할 예정이다"

#### 행정기관명 표기
- 정부 부처: "기후에너지환경부", "과기정통부", "기상청" (2025.10 개편 이전 기사만 "환경부")
- 산하기관: "국립환경과학원", "한국해양과학기술원(KIOST)"
- 위원회: "2050탄소중립녹색성장위원회", "국가기후위기대응위원회"

### 2. 해외 정책·연구 (500~700자)

#### 소스 원칙
- **공신력 있는 국제기구의 공식 발표를 최우선**: WMO, IEA, UNFCCC, NASA, NOAA, UNEP, IPCC, GCF, ESA
- **Carbon Brief, The Guardian 등 기후 전문 매체**의 심층 보도도 적합
- Nature, Science 등 학술지의 뉴스 기사는 이 섹션에서 **다루지 않는다** (→ 논문 소개는 '최신 연구 동향' 섹션으로)

#### 외국인 이름 표기 규칙
- **영어 원문 그대로 표기한다** (한글 음역 사용하지 않음)
- 예시: ~~피터 잘잘~~ → Peter Zalzal, ~~슈테판 라흠스토르프~~ → Stefan Rahmstorf
- 직함이 있으면 한국어로 번역 후 영어 이름 연결: "환경방어기금의 Peter Zalzal 부총재는"

#### 구조 패턴
```
[기관 풀네임(약어)]은(는)/의 [보고서/연구]에 따르면, [핵심 내용 요약].
→ 구체적 분석 결과 (2~3문장, 수치 포함)
→ 지역별/분야별 세부 내용 (1~2문장)
→ 전문가/사무총장 발언 인용 또는 전망 (1~2문장)
```

#### 실제 패턴 예시
- **첫 문장**: 기관명 + 보고서/발표 소개
  - "세계기상기구(WMO)는 최신 보고서를 통해 ~라고 밝혔다."
  - "국제에너지기구(IEA)의 최신 보고서에 따르면, ~것으로 나타났다."
- **원문 보고서 링크**: 별도 참고자료가 있으면 "※ 원문: [제목](URL)" 형태로 추가

### 3. 최신 연구 동향 (600~800자)

#### 소스 원칙
- Nature, Nature Climate Change, Nature Geoscience, Nature Communications 등 **Nature 계열 우선**
- Science, Science Advances, **PNAS** 등 주요 종합 저널도 **골고루 검색**
- Atmospheric Research, ACP 등 대기과학 전문 저널도 포함
- **논문 링크는 반드시 해당 논문의 고유 페이지 URL**(DOI)로 연결. `web_fetch`로 접속하여 제목과 DOI가 정확한지 반드시 확인

#### 분량
- 국내/해외 기사보다 **분량을 넉넉히** 작성 (600~800자)
- 연구배경, 연구방법, 주요 결과, 시사점 4가지 요소가 모두 충분히 전달되어야 한다

#### 구조 패턴
```
[연구 배경/문제 제기] (1~2문장)
→ "본 연구에서는 [연구방법]을 활용하여 [연구대상]을 분석하였다." (1문장)
→ "연구 결과, [핵심 발견]인 것으로 나타났다." (3~4문장, 수치와 데이터 충분히 포함)
→ 연구진 인용 또는 학술적 의의 (1~2문장)
```

#### 실제 패턴 예시
- **첫 문장**: 배경/문제 제기로 시작
  - "열대 지역 상부 대류권에서 관찰되는 ~은 전 지구적으로 중요한 과정으로 알려져 있으나, ~에 대한 규명은 거의 이루어지지 않았다."
  - "기후변화의 영향으로 남극 빙하의 해빙 속도가 가속화되어 ~"
- **연구방법**: "본 연구에서는 ~을 활용하여/~을 대상으로"
- **연구결과** (분량을 충분히): "연구 결과,", "분석 결과,", "그 결과," 로 시작. 핵심 수치 3~4개를 반드시 포함
- **마무리**:
  - 연구진 인용: "연구진은 '...'라며, '...'이라고 강조했다."
  - 의의 제시: "본 연구는 ~을 밝혀내며, ~의 필요성을 강조한다."

## 문체: AI식 요약체 피하기

요약은 사람이 원문을 읽고 정리한 글처럼 읽혀야 한다. 아래 패턴이 반복되면 문장을 다시 쓴다.

| 피할 패턴 | 이유 | 대안 |
|----------|------|------|
| "또한 ~했다. 아울러 ~했다. 한편 ~했다."처럼 접속사로 문장을 기계적으로 잇기 | 내용 간 관계가 드러나지 않고 나열로 읽힘 | 인과·대비 등 실제 관계가 드러나도록 문장을 합치거나 순서를 바꿈 |
| "이는 ~라는 점에서 의미가 있다", "~할 것으로 기대된다"로 매번 마무리 | 모든 항목이 같은 결말로 끝남 | 원문의 인용·향후 일정·구체 수치로 마무리하고, 시사점은 꼭 필요할 때만 씀 |
| "주요 내용은 다음과 같다", "첫째·둘째·셋째" 식 개조식 전개 | 뉴스레터 본문이 보고서 요약표처럼 보임 | 핵심 1~2개를 중심으로 서술하고 나머지는 한 문장으로 묶음 |
| 원문에 없는 일반론 추가 ("기후위기가 심화되는 가운데", "전 세계적으로 주목받고 있다") | 분량만 늘고 정보가 없음 | 첫 문장부터 이 기사만의 사실(주체·행위·수치)로 시작 |
| 같은 종결어미 3회 이상 연속 ("~밝혔다. ~밝혔다. ~밝혔다.") | 단조로움 | 종결어미 패턴 예시를 섞어 씀 |
| 번역투 ("~에 있어서", "~를 통해 ~가 이루어졌다", "~하는 것으로 보여진다") | 부자연스러운 한국어 | 능동 서술로 바꿈 ("~에서", "~가 ~했다", "~로 보인다") |

**예시**

- ❌ 기후에너지환경부는 배출권거래제 개편안을 발표하였다. 또한 유상할당 비율을 확대하기로 하였다. 아울러 산업계 의견을 수렴할 계획이다. 이는 탄소중립 달성에 있어서 중요한 의미가 있다.
- ✅ 기후에너지환경부는 9월 25일 배출권거래제 제4차 계획기간 개편안을 발표하고, 발전 부문 유상할당 비율을 현행 10%에서 단계적으로 50%까지 높이기로 하였다. 산업계 부담을 고려해 철강·시멘트 등 무역노출 업종은 무상할당을 유지하며, 10월 중 공청회를 거쳐 연내 확정할 예정이다.

(예시의 수치는 문체 비교용 가상 값이다.)

## 금지 사항

1. **기사 제목 임의 생성/변형 금지**: 반드시 원문 기사의 정확한 제목을 사용
2. **출처 매체 조작 금지**: 실제 기사가 게재된 매체명만 기재. 확인되지 않은 매체를 출처로 적지 않음
3. **소규모 언론사 사용 금지** (국내): 주요 대형 언론사 또는 정책브리핑만 사용
4. **해외 섹션에 논문 뉴스 혼입 금지**: Nature/Science의 연구 결과 뉴스는 '최신 연구 동향'으로 분류
5. **외국인 이름 한글 음역 금지**: 영어 원문 그대로 표기
6. **부정확한 논문 링크 금지**: 저널 목록 페이지가 아닌, 해당 논문의 고유 페이지 URL 사용
7. **의견·평가 삽입 금지**: "놀랍게도", "당연히", "안타깝게도" 등 주관적 표현 사용 금지
8. **구어체 금지**: "~인데요", "~거든요", "~잖아요"
9. **과도한 수식어 금지**: "획기적인", "혁신적인" 등은 원문에 있을 때만 사용
10. **불필요한 반복 금지**: 같은 내용을 다른 말로 재서술하지 않음
11. **출처 누락 금지**: 모든 기사/논문에 반드시 출처 표기
12. **정형화된 AI식 요약체 금지**: 기계적 접속사 나열, 상투적 마무리, 원문에 없는 일반론 추가 금지 (위 '문체: AI식 요약체 피하기' 참고)
